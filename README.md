# Music Fetcher Pro（GUI 使用说明）

本项目用于将 QQ 音乐歌单映射到 B 站音频资源，并支持单曲搜索与下载。

## 1. 适用环境
- Windows 10/11
- Python 3.11（推荐）
- 已安装依赖：`pip install -r requirements.txt`
- 已安装 `ffmpeg` 并加入 `PATH`（或放到程序同目录）

## 2. 启动 GUI
在项目根目录执行：

```bat
.\.venv\Scripts\python.exe main_gui.py
```

打包后可直接双击：

```text
dist\music_fetcher_pro.exe
```

## 3. 界面总览
左侧是功能导航，右侧是当前页面内容和日志区：
- `歌单批量处理`：按 QQ 歌单批量匹配并下载
- `单曲精确搜索`：按关键词搜索 B 站音频，手动选择后下载
- `打开下载目录`：快速打开当前下载目录
- `取消任务`：中断正在执行的任务

底部 `实时日志` 会显示当前进度、错误原因和任务结果。

## 4. 歌单批量处理（推荐流程）
1. 在 `歌单URL` 填入 QQ 歌单链接。
2. 设置 `start` 和 `limit`（控制从第几首开始、最多处理多少首）。
3. 设置 `outdir`（Excel 输出目录）和 `audio_dir`（音频保存目录）。
4. 选择音频格式：
   - `mp3`：可设置码率（如 320）
   - `m4a`：固定 128
   - `flac`：无损，忽略码率
5. 需要只导出不下载时勾选 `仅导出不下载`。
6. 点击 `开始处理`，观察进度条和日志。

处理完成后会在 `outdir` 生成：
- `xxx_资源清单.xlsx`
- `xxx_未匹配清单.xlsx`

## 5. 单曲精确搜索（推荐流程）
1. 切换到 `单曲精确搜索`。
2. 输入关键词（如 `歌名 歌手`）。
3. 设置 `max`（返回结果数）。
4. 点击 `搜索`，结果会显示在表格中。
5. 在结果表多选目标条目。
6. 点击 `下载选中音频`。

## 6. 参数说明（GUI 常用）
- `start`：从歌单第几首开始处理（从 0 开始）
- `limit`：本次最多处理条数
- `outdir`：Excel 结果输出目录
- `audio_dir`：音频输出目录
- `format/quality`：下载音频格式与质量
- `保留合作歌手`：清洗歌单时是否保留合作歌手信息

## 7. 配置与日志位置
- 用户配置：`%USERPROFILE%\.qqmusic2bilibili.ini`
- 日志文件（源码运行）：`logs\app.log`
- 日志文件（exe 运行）：`%LOCALAPPDATA%\qqmusic2bilibili\logs\app.log`

## 8. 常见问题
- 启动后下载失败并提示 ffmpeg：
  - 安装 ffmpeg 并加入系统 `PATH`
  - 或把 `ffmpeg.exe` 放到程序同目录

- 搜索结果少或未命中：
  - 改用 `歌名 + 歌手` 关键词
  - 增大 `max`
  - 查看日志中的过滤与评分信息

- 任务执行中界面切换受限：
  - 属于正常行为，避免任务中切页导致状态不一致
  - 可先点击 `取消任务` 再切换功能页

## 9. 典型使用建议
- 第一次使用先用小范围测试：`start=0, limit=5`
- 批量前先确认下载目录可写
- 长任务建议保留日志，便于问题定位
